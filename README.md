                               🌱 EcoWMS — Smart Waste Management System
                               
EcoWMS is a modern, web‑based Waste Management System designed to streamline waste disposal requests for residents and empower administrators
with intelligent tools to monitor waste bins and coordinate collections efficiently.

The platform bridges the gap between public households and utility management through:

🗓️ Automated scheduling
📡 Real‑time bin sensor simulation
💾 Reliable database persistence

Built with Object‑Oriented Programming (OOP) principles, EcoWMS ensures robust maintainability, modular design, and clean code conventions.

🧩 Tech Stack

Frontend: React
Backend: Spring Boot
Database: MySQL

👥 Collaboration
This project was developed collaboratively, with responsibilities divided between backend/API integration and frontend design.
